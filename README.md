# Online Purchase Website

## 📌 About the Project

The Online Purchase Website is designed to provide users with a simple and convenient online shopping experience. The website is developed using HTML, CSS, JavaScript, and XML. It allows users to browse products and explore an online shopping interface.
 live demo :
https://muthuanddhanustrore.netlify.app
## 🎯 Objective

The main objective of this project is to design an online shopping website using CSS, JavaScript, and XML to understand web designing, styling, and interactive functionalities.

## ✨ Features

- User-friendly interface.
- Attractive webpage design using CSS.
- Interactive features using JavaScript.
- XML for storing and managing product information.
- Easy navigation between web pages.
- Simple online shopping layout.

## 🛠️ Technologies Used

- **HTML:** Creates the structure of web pages.
- **CSS:** Provides styling, colors, layouts, and designs.
- **JavaScript:** Adds interactive functionality.
- **XML:** Stores and organizes product details.

## 📄 Web Pages

The website consists of different web pages to provide a smooth online shopping experience.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all HTML, CSS, JavaScript, and XML files are available.
4. Open the main HTML file using a browser or Live Server.
5. Explore the website.
